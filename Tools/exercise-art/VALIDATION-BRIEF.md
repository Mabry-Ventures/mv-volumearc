# Exercise illustration validation brief

VolumeArc's catalog ships 133 line-drawing illustrations under
`App/Assets.xcassets/ExerciseIllustrations/<id>.imageset/<id>.png`. They
were generated by Codex CLI's `image_generation` tool over five sessions
on 2026-04-26. We're now running two independent validation passes:

- **Pass B** — this brief, executed by Codex CLI itself
- **Pass A** — same brief, executed by a Claude agent for a
  second-opinion cross-check

The two reports get reconciled at the end; any illustration flagged by
EITHER pass for re-roll gets one re-roll attempt before we accept.

## Inputs

1. **Catalog source of truth** —
   `VolumeArcNative/Sources/VolumeArcCore/Workout/ExerciseCatalog+Entries.swift`.
   Each entry has `id`, `name`, `pattern`, `primaryEquipment`,
   `secondaryEquipment`, `cues`, and the VOL-105 additive fields
   (`primaryMuscles`, `unilateral`, `lengthenedPositionEmphasis`, etc).
   The expected pose for each illustration follows from `name` +
   `pattern` + `primaryEquipment`, with the framing rules in
   `Tools/exercise-art/STYLE.md`.

2. **Style canon** — `Tools/exercise-art/STYLE.md`. Defines line weight,
   color, background, character continuity, pose framing per movement
   family.

3. **Anchor reference** —
   `App/Assets.xcassets/ExerciseIllustrations/back-squat.imageset/back-squat.png`.
   The first illustration generated; locks the coach character (short
   hair, athletic shorts + tank top, neutral build) that every other
   pose should match.

## Three scoring axes (1–5, integer)

| Axis | Question |
|---|---|
| `style_score` | Does the line weight, background tone, and overall illustration aesthetic match the anchor + STYLE.md? |
| `character_score` | Is this the same coach character as the anchor — same hair, same build, same clothing, same level of facial detail? |
| `pose_score` | Does the pose actually communicate the named exercise? Equipment present where needed, body angle correct, recognizable to a strength coach? |

Anchor scoring rubric:

- **5** — indistinguishable from the anchor's quality, no concerns
- **4** — clean and recognizable, minor stylistic drift
- **3** — usable but visibly imperfect; a careful reviewer would notice
  the inconsistency
- **2** — wrong on a meaningful axis (different character, wrong pose
  framing, missing equipment)
- **1** — fundamentally broken (unrecognizable exercise, missing figure,
  wildly off-style)

## Output format

Write your findings to `Tools/exercise-art/validation-report-<pass>.md`
where `<pass>` is `codex` (Pass B) or `claude` (Pass A). The file must
have:

1. **Summary header** — total reviewed, count by lowest score per row,
   recommended re-roll list (any row whose minimum-of-three-scores ≤ 3).

2. **Per-exercise table** — one row per illustration:

   ```
   | id | style | character | pose | concern | reroll? |
   ```

   `concern` is a single short sentence on the worst issue you saw, or
   "none" if all scores are 4-5. `reroll?` is `yes` if `min(scores) ≤ 3`
   else `no`.

3. **Sorting** — the table sorted ascending by `min(scores)` so the
   worst illustrations are at the top.

## Validation rules

- **Don't be lenient.** A 5/5/5 should be rare and earned. Most decent
  illustrations should land 4/4/4. Anything that an actual reviewer
  would say "huh, that looks off" gets a 3 or below.
- **Don't penalize subtle biomechanical issues** that wouldn't be
  visible to a non-coach. We're shipping a v1 illustration, not Olympic
  form coaching. The bar is "recognizable as the named lift."
- **Flag any character drift** — if the figure suddenly has different
  hair, different clothing, or a meaningfully different build vs the
  anchor, that's a `character_score` ≤ 3 even if everything else is
  fine.
- **Equipment matters** — a "leg press" without the leg-press machine
  drops to `pose_score` ≤ 2. A "cable lateral raise" without a visible
  cable + stack drops to `pose_score` ≤ 2.
- **Side-by-side sanity check** — sample 5-10 random IDs and view them
  next to the anchor (`back-squat.png`) before scoring. Calibrate your
  rubric.

## Don't modify

- The illustrations themselves. Don't re-generate or fix anything in
  this pass. Just score + report.
- The catalog source.
- Any other files in the repo.

## When done

Print: total reviewed, the 10 lowest-scoring IDs (in ascending min-score
order), and the absolute path of the report file. That's it.
